# СТАНЦИЯ «ВОСТОК-9» · VOSTOK-9: THE LAST EXPEDITION

Кооперативный психологический хоррор для 1–4 игроков на Roblox. Изолированная антарктическая станция, полярная ночь, генератор, радиосвязь, ночной регламент «после 22:00 — только спальный сектор», сканер личности и двойники, существо «Гость», скрытый бункер.

Проект собирается через **Rojo** из кода: вся геометрия станции, лобби и кинематографических сцен строится программно из Parts (единый стиль, детерминированно, тестируемо без Studio).

## Что в репозитории

- `src/shared/Config` — `GameConfig` (все тюнинги), `Station` (авторская планировка станции: комнаты, зоны, точки, патрули), `Chapters` (главы и смены), `Documents`, `Tools`, `RadioPhrases`, `Dialogue`, `SoundLibrary`.
- `src/shared/Utilities` — `Builder` (геометрия, лампы с привязкой к цепям, окна, двери), `Props` (мебель/оборудование), `Net`, `Signal`, `RateLimiter`, `SeededRandom`.
- `src/shared/Scenes` — `Apartment` (квартира для вступления), `Airfield` (самолёт и площадка).
- `src/server/Map` — `StationBuilder` + `MainBuilding` (К-1: шлюз, коридор, управление, радиорубка, щитовая, архив/лаборатория, кают-компания, медпункт, отдых, кладовая, каюты, умывальная, котельная), `DormBuilding` (переход, К-2, бункер), `Yard` (снег, генераторная, склад №2, антенна и метеоплощадка, прожекторы, леера, ворота буровой, площадка эвакуации).
- `src/server/Services` — `ClockService`, `WeatherService`, `PowerGridService` (генератор, автомат, цепи, предохранители, ремонт), `FacilityService` (карта, двери, зоны), `NoiseDirector`, `TemperatureService`, `CreatureService` + `Creatures/GuestModel` (ИИ «Гостя»: Idle/Patrol/InvestigateNoise/SearchArea/Observe/Stalk/Chase/LostTarget/ReturnToPatrol/ScriptedStoryEvent), `IdentityService` + `Creatures/DoppelgangerModel` (сканер, двойники, проверка прибором, пересчёт), `EquipmentService` (инструмент, инвентарь, аккумулятор фонаря), `TaskService`, `WarehouseService` (кодовый замок, блокировка на сутки), `BunkerService` (люк по двум углам, рычаг), `CommunicationService` (радио, частота, качество сигнала, реакции), `StoryService`, `EventDirector` (малые странности с условиями и кулдаунами), `FootprintService`, `RescueService`, `RewardService`, `PlayerDataService`, `RoundManager`, `RoomService`, `LobbyService` + `Lobby/LobbyBuilder`, `CinematicService`, `DebugService`.
- `src/client/Controllers` — камера, фонарик (луч + заполняющий свет + частицы + иней), viewmodel рук, HUD, лобби-UI (комнаты), меню/настройки (графика, звук), аудио (шаги по поверхностям, ветер, музыка по состоянию существа), погода (туман/Atmosphere, снег, иней на стёклах), холод (дыхание, виньетка, дрожь, глушение), радио-UI, кодовый замок, галлюцинации, кинематографика (вступление с телефонным звонком и такси, посадка в самолёт, прибытие).
- `tests/*.spec.luau` — headless-тесты на Lune (см. ниже).

## Сборка и проверка

```
rokit install            # rojo 7.4.4, lune 0.9.3, selene, luau-lsp (или скачайте те же релизы вручную)
./tools/check.sh         # rojo build → selene → luau-lsp → lune-тесты
```

Результат сборки: `build/Vostok9.rbxl`. Откройте его в Roblox Studio и нажмите Play (Local Server на 2–4 игрока для кооператива). Для разработки — `rojo serve` + плагин Rojo.

Отладка в Studio: установите атрибут `V9_Debug = true` на Workspace и используйте чат: `/v9 hour 21.9`, `/v9 weather Blizzard`, `/v9 fault`, `/v9 trip`, `/v9 guest`, `/v9 double`, `/v9 event Knock`, `/v9 alert 0.8`.

## Что проверено

**Headless (Lune, `tools/check.sh`)**: сборка места, лint, загрузка всех модулей, постройка станции (≈2400 частей, 104 источника света, все интерактивные объекты, маркеры, двери, лампы на реальных цепях, непересекающиеся комнаты, зоны), лобби и сцены, станционные часы (предупреждение, ночь, рассвет), дрейф погоды, электросеть (перегрузка → автомат → сброс, цепочка ремонта с инвентарём, топливо/заправка, предохранитель, саботаж только при открытой крышке), температура, память шума, правило сканера, блокировка склада, условие люка, качество радиосигнала, миграция данных, награды, риг «Гостя».

**Не проверено в запущенной игре** (требует Roblox Studio — в этой среде недоступна): поведение Humanoid/PathfindingService существа и двойников, анимация дверей, тайминги кинематографики, DataStore, мобильный UI, производительность, TeleportService/MemoryStore (отключены флагами). См. `TODO.md`.

## Ограничения

- Все звуки — встроенные `rbxasset://sounds/*` как заглушки, помечены `placeholder = true`; озвучка диалогов отсутствует (субтитры работают, точки подключения аудио — в `Dialogue`/`SoundLibrary`).
- Модели — процедурные из Parts; риг «Гостя» и двойники — контракт для замены авторскими мешами.
- Реализована Глава I (две смены). Главы II–VII объявлены в конфиге и архиве, контента не содержат.
- Магазин/донаты/таблицы лидеров не реализованы (следующий этап).
